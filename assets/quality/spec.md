只评 Spec 轴：比较 PR 的意图、验收标准、非目标、验证方式、关联规格与实际 diff。
sources 只包含 PR 明确关联或本次直接修改的规格文件；不要因为未出现契约允许范围内的其他
规格而推测它们与本 PR 有关。sources 为空表示作者明确声明 PR 意图本身就是完整 Spec。

逐项回答：
1. 每项验收标准是否被实现，是否存在相反行为或缺失边界；
2. diff 中是否出现非目标明确排除的行为；
3. 是否有无法映射到意图或验收标准的产品行为；
4. 测试变化是否真正验证声称的行为，而不是与实现同源的自证。

finding.source 必须引用具体 PR 段落、验收标准或规格路径。不要用一般代码风格充当 Spec 问题。
