## Goals

修复质量初始化入口对 Git 工作树状态的首条记录解析错误：当工作树只有一个未暂存的、初始化允许处理的 `.coding-x/quality.json` 改动时，当前实现会丢失状态行开头的空格并把合法路径误判为无关改动。修复后应准确识别 Git 的状态字段和路径，同时继续拒绝任何真正无关的改动。

## Non-Goals

- 不放宽初始化允许修改的文件集合，也不允许脏工作树中的其他产品改动混入初始化。
- 不重做整个初始化流程、Git 抽象或远端规则管理。
- 不更新 Codex 审计版本，不处理自动轮询、队列或更多 Agent 编排。
- 不把临时规避方式写成正式流程；目标是消除误判本身。

## Risk

这里处理的是初始化前的脏工作树安全边界。错误修复若过宽，可能让无关改动混入受保护政策生成；若过窄，则继续阻塞合法的稳定裁判更新。实现必须保持失败关闭，只修正状态记录解析，不新增通配放行。代码位于受保护质量路径，PR 必须使用独立、有期限的政策例外并由 owner 明确批准；未批准不得合并。
