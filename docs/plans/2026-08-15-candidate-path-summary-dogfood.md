# 候选验证顶层路径摘要夹具

本计划只覆盖 Shadow Dogfood 的 US-001。实现为隔离纯函数，不接入引擎生产路径；返回按插入顺序排列的只读 `Map`，每组持有独立路径数组。

## 完成合同

| 验收标准                                                     | 验证方式                                                               |
| ------------------------------------------------------------ | ---------------------------------------------------------------------- |
| 空输入、分隔符规范化、重复路径、根文件、稳定顺序、输入不变性 | `npm test -- --run src/dogfood/candidate-path-summary.test.ts`         |
| 既有行为不变                                                 | PRD `qualityChecks` 中的完整机械门禁，包含 `npm test -- --run`         |
| 本 story 的独立验收边界                                      | Validator 只运行 PRD 指定的 format、lint、typecheck 与目标测试四条命令 |

## 黄金原则逐项对照

| 原则                  | 适用性与设计裁决                                                                   | 完成证据                                  |
| --------------------- | ---------------------------------------------------------------------------------- | ----------------------------------------- |
| 1. 可证伪完成合同     | 适用；逐项绑定字面量断言与固定命令                                                 | 目标测试及上表命令全部通过                |
| 2. 生成方不得自签通过 | 适用；Builder 只提交候选，完整门禁由引擎执行，独立 Validator 按 PRD 限定范围复核   | `passes=true` 不替代后续 `validated=true` |
| 3. 自治扩大需同步防线 | 不适用；纯函数不增加写入、执行、合并、部署或删除能力                               | 仅新增隔离夹具与单元测试                  |
| 4. 优先复用原生能力   | 适用；只使用 JavaScript 字符串、数组、`Map` 与 `Set`，不增加依赖或 runner 专用逻辑 | 依赖清单不变，typecheck 与 lint 通过      |
| 5. 失败恢复与真实回归 | 适用；先覆盖空值、重复值和混合分隔符等边界，再覆盖正常分组；期望值使用独立字面量   | 目标测试先红后绿，完整回归通过            |
