# 设计决策（ADR）

一事一文件，文件名 `NNN-标题.md`（编号从 001 递增），模板见 coding-x 插件 `templates/docs/decision.md`。

## status 约定

- `active`：决策生效中。带重新立项触发条件的「暂缓」也属于此类——暂缓本身是生效中的决策（先例：001 MCP 暂缓）。
- `superseded`：被后续决策取代，正文头部注明被哪个编号取代。
- `rejected`：拒绝记录——评估后决定**不做**且无触发条件的方向/请求，也一事一文件，记录否因与被否备选，防止同一提案反复重议。新提案进来先查这里和暂缓类 ADR，命中就引用先例而不是重新论证。
