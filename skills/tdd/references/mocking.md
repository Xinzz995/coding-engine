# 边界模拟

只在不可控或代价过高的系统边界考虑模拟：

- 外部支付、邮件或第三方 API；
- 时间、随机性和故障注入；
- 无法为测试安全提供的文件系统或远程存储；
- 数据库无法使用隔离测试实例时的最外层适配器。

优先使用真实的内部模块、内存实现、临时目录、测试数据库和本地协议服务器。不要模拟自己的
领域类、内部协作者或可以直接运行的代码路径。

在边界处注入小而专用的接口：

```typescript
function chargeOrder(order, paymentGateway) {
  return paymentGateway.charge(order.total);
}
```

让每个模拟只表达一种外部结果。若模拟需要根据大量内部调用细节分支，通常说明接口过宽或测试
正在验证实现结构。
